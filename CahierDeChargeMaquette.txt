2. DÉTAIL DU MODULE PATIENT (Spécifications techniques)

2.1 User Stories

| ID        | En tant que | Je veux                                | Afin de                                    |
| --------- | ----------- | -------------------------------------- | ------------------------------------------ |
| PAT-US-01 | Patient     | Réserver un ticket en ligne            | Ne pas attendre physiquement à la clinique |
| PAT-US-02 | Patient     | Voir mon temps d'attente estimé        | Organiser mon temps en conséquence         |
| PAT-US-03 | Patient     | Être notifié quand c'est mon tour      | Ne pas manquer mon tour                    |
| PAT-US-04 | Patient     | Choisir mon médecin                    | Consulter le praticien de mon choix        |
| PAT-US-05 | Patient     | Annuler ma réservation                 | Libérer ma place si je ne peux pas venir   |
| PAT-US-06 | Patient     | Voir l'historique de mes consultations | Garder une trace de mes visites            |

2.2 Règles de gestion

| ID        | Règle                                                                                                 | Priorité |
| --------- | ----------------------------------------------------------------------------------------------------- | -------- |
| RG-PAT-01 | Un patient ne peut avoir qu'un seul ticket actif (waiting ou in\_progress)                            | Critique |
| RG-PAT-02 | Le temps d'attente estimé = (position dans file × 15 min) - (temps moyen médecin × patients en cours) | Haute    |
| RG-PAT-03 | Notification push envoyée 5 min avant et au moment de l'appel                                         | Haute    |
| RG-PAT-04 | Annulation possible jusqu'à 5 min avant l'appel estimé                                                | Moyenne  |
| RG-PAT-05 | Priorité 1 (Urgence) = appel immédiat si médecin disponible                                           | Critique |

2.4 API Endpoints Patient

| Méthode | Endpoint                     | Description               | Auth |
| ------- | ---------------------------- | ------------------------- | ---- |
| POST    | `/api/patients/`             | Créer un ticket           | JWT  |
| GET     | `/api/patients/me/`          | Mon ticket actif          | JWT  |
| GET     | `/api/patients/`             | Liste (filtrée par email) | JWT  |
| PATCH   | `/api/patients/{id}/cancel/` | Annuler mon ticket        | JWT  |
| GET     | `/api/patients/history/`     | Mon historique            | JWT  |
